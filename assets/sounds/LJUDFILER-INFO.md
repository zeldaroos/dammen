# Ljudfiler för Fiskdam

## Nuvarande lösning: Web Audio API
Jag har skapat en tillfällig lösning med Web Audio API som genererar enkla jingle-ljud.

## För att använda riktiga ljudfiler

### Alternativ 1: Gratis ljudeffekter
Ladda ner gratis ljudeffekter från dessa källor:

1. **Freesound.org** (https://freesound.org/)
   - Sök efter "jingle", "chime", "bell", eller "ding"
   - Ladda ner MP3 format
   - Döp om till jingle1.mp3, jingle2.mp3, etc.

2. **Mixkit.co** (https://mixkit.co/free-sound-effects/)
   - Gratis ljudeffekter utan krav på attribution
   - Bra för enkla notification sounds

3. **Zapsplat.com** (https://www.zapsplat.com/)
   - Stor samling gratis ljud
   - Kräver gratis konto

### Alternativ 2: Skapa egna ljud
Du kan använda verktyg som:
- **Audacity** (gratis) - för att redigera och skapa ljud
- **GarageBand** (Mac) - för att skapa enkla jingles
- **Online Tone Generator** - för enkla toner

### Filkrav:
- Format: MP3 (rekommenderat för webbkompatibilitet)
- Filnamn: jingle1.mp3, jingle2.mp3, jingle3.mp3, jingle4.mp3
- Placering: assets/sounds/
- Längd: 1-3 sekunder för bäst resultat

## Installera ljudfilerna
1. Ladda ner eller skapa 4 ljudfiler
2. Döp om dem till jingle1.mp3, jingle2.mp3, jingle3.mp3, jingle4.mp3
3. Flytta dem till `assets/sounds/` mappen
4. Nu kommer webbsidan automatiskt spela ljuden när du klickar på fiskarna!
